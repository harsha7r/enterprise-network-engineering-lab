# Enterprise Network Engineering Lab

## Project Overview

This project demonstrates the design, configuration, testing, and troubleshooting of a simulated enterprise network using Cisco Packet Tracer.

## Objectives

- Design a small enterprise network topology.
- Configure IPv4 addressing and subnet masks.
- Implement VLANs for departmental network segmentation.
- Configure inter-VLAN routing.
- Implement DHCP and DNS services.
- Apply network access controls.
- Troubleshoot connectivity and configuration issues.
- Document network configurations, tests, and incident resolutions.

## Network Departments

| Department | VLAN | Planned Subnet |
|---|---:|---|
| HR | 10 | 192.168.10.0/24 |
| IT | 20 | 192.168.20.0/24 |
| Finance | 30 | 192.168.30.0/24 |

## Tools and Technologies

- Cisco Packet Tracer
- IPv4 and TCP/IP
- Ethernet switching
- VLANs and trunking
- Inter-VLAN routing
- DHCP and DNS
- Access Control Lists (ACLs)
- Network troubleshooting
- GitHub documentation

## Project Implementation

The network will be implemented and tested in stages. Configuration details, screenshots, test results, and incident reports will be added as each stage is completed.

## Repository Structure

- `topology/` — Packet Tracer project file
- `docs/` — network design and technical documentation
- `screenshots/` — implementation and testing evidence
- `configs/` — configuration notes

## Validation

Connectivity, addressing, routing, name resolution, and access-control behaviour will be tested and documented after implementation.
